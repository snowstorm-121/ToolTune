# T2 数据工程与评测协议（2026-10-22）

状态：本文记录保留的v1原始哈希抽样。用户已确认均衡抽样，活动协议为v2-balanced，T2验收见 `T2-balanced-protocol.md`。没有运行正式Validation/Test模型推理，没有选adapter，没有质量提升成绩。

## 来源和过滤

Glaive Function Calling v2 revision `e7f4b6456019f5d8bcb991ef0dd67d8ff23221ac`，Apache-2.0。原始JSON为271,190,065字节、112,960条，仅来源train。SHA256：`e9b5d671812b5ca2fbd7b625a37d5c99a19576c37252cdc806defe256aea6dad`。见 `data/manifests/raw.json`。这些历史工具返回不是真实API执行证明。

严格解析保留99,108条完整对话，隔离13,852条。隔离原因：角色/顺序损坏7,619；无效schema 3,109；JSON/字段错误372；未知工具24；同名工具349；不完整对话1,454；参数schema错误804；调用语法错误115；空目标2；混合动作2；空消息2。每条隔离记录保留source ID和原因，通过原始文件行号对应的数组索引可回溯。

保留来源的可用工具数：0个34,594条、1个51,874条、2个12,640条。解析出的user消息240,387、assistant决策309,010、tool历史68,623。角色/格式合格不是语义标签全面正确的证明。

Glaive经常把arguments的嵌套JSON包在单引号中，外层因此不完全是JSON。解析器采用有限语法和JSONDecoder，先消费完整嵌套JSON再确认封装引号，不执行Python、不用eval、不做全局引号替换。多调用、混合动作、损坏边界、重复JSON键、不合法数值隔离。JSON Schema采用Draft7和当前安装的FormatChecker；不自动收紧上游未声明的additionalProperties，不读取远程ref。

## 分组与长度

以完整来源对话、工具签名家族、重复/规范化问法、近重复问法构建传递连通分组。工具签名保留工具名、参数名/结构、required、enum等约束，忽略说明文字；properties中名为title/description的真实参数不会被误删。数字和双引号文本占位、大小写折叠、Unicode词项用于模板去重；8词及以上问法采用词三元组Jaccard>=0.85，短问法仅规范化精确比较。这不是语义去重或预训练污染排除。

产生21,369组，最大组77,025条。按seed=42的组哈希固定80/10/10区间；**不保证组大小均衡**，不打散大组、不按模型表现重分配。

已确认并实施的v2方案：不改变来源分组和训练集，在同一Validation/Test池内按固定哈希分别抽取相同数量的调用/非调用。Validation 100+100，Test 95+95，共190。没有补造标签或按模型表现选题；这是**均衡诊断分布**，不是原始分布估计。新版本及与v1的关系单独保存，原始v1不覆盖。

## mask和金标签边界

每条决策只把之前消息和工具作为条件，监督最后一个assistant及模板结束token。tool response只作为已发生的历史，未来返回不进入目标。使用官方Instruct原生template、完整token前缀一致性检查和经测试的assistant-only loss，长样本整条隔离。

4,500条选中样本全部与上游ChatDataset/CacheDataset的tokens和offset一致。`mask_examples.json`含真实调用、普通回答、工具不适配非调用、多轮tool历史的逐token mask；`long_rejection_example.json`保存真实561-token样例整条拒绝的证据。普通回答示例本身可有来源代码/事实问题，此处只检查训练表示，不宣称回答正确。

由源标记可靠导出call/no_call。来源没有独立“追问/无适配工具”动作字段：可见追问和拒绝文本，但不能凭问号或拒绝关键词把候选自动变成金标准。当前两个专门子集的已审定标签数均为0，对应指标应为N/A；一般no_call仍进入主指标。若后续标注子集，需在首次Test推理前固定规则和标签。

## 审计与复现

完整来源组、家族、规范化问法跨split交集均为0；对选中样本的全部历史user问法独立执行跨集词三元组扫描，>=0.85的近重复对数为0。结论仅限明确的规范化和相似度规则，不证明语义/预训练层面无泄漏。

首次全量准备255.46秒。第二次重新解析并反转输入顺序，所有来源组和split完全重现；按冻结哈希边界重建选题，六个records/upstream JSONL文件逐字节一致，19.73秒。日志：`artifacts/t2-prepare.log`、`artifacts/t2-reproduction.log`、`artifacts/t2-reproduction.json`。数值非有限性防护的代码变化已记录，未改变来源计数、划分或所选字节。

另导出200条训练侧smoke样本和20条训练侧check样本，source不重叠；它们全部来自Train，**不是正式Validation/Test，也不声称组不重叠或泛化成绩**。此阶段只导出，未在其上扩训。

`data/manifests/v1/contract.json`固定数据、来源/样本ID、模板、依赖与代码哈希。`validate`检查文件哈希、来源/组不交叉及训练payload不含expected_*元数据。完整测试/最终验证结果另存 `artifacts/final-verification.json`。正式模型/adapter/评分器的首次Test运行契约需在T4补齐，当前不是已经完成的实验成绩。
